## ¿Qué es un struct?

1. Un **struct** agrupa varios valores relacionados bajo un solo tipo, cada uno con su propio nombre (*campo*) y tipo.
2. A diferencia de una tupla, cada campo tiene un nombre. El código deja de depender del orden para saber qué representa cada valor.

<br>

```rust
struct Punto {
    x: f64,
    y: f64,
}

fn main() {
    let origen = Punto { x: 0.0, y: 0.0 };
    println!("({}, {})", origen.x, origen.y);
}
```

## Unit structs vs. structs con campos

1. No todos los structs necesitan guardar datos. Un ***unit struct*** se declara sin campos ni llaves, solo como marcador de tipo:

```rust
struct Marcador;

fn main() {
    let m = Marcador;
}
```

2. Sirven como marcador de tipo: un concepto con identidad propia, sin datos que cargar.

## Cuál de los dos

<div class="important-note">

Un **unit struct** basta cuando el tipo solo necesita comportamiento, sin estado
propio.

Un **struct con campos** corresponde cuando cada instancia debe ser distinta porque
sus valores lo son.

</div>

Los métodos que le dan comportamiento a un unit struct se declaran en un bloque
`impl`, que llega en 3.4.
