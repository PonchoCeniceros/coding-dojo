## `#[test]` y `cargo test`

Una función marcada con `#[test]` se compila solo al correr los tests. `cargo test`
las ejecuta todas y reporta cuáles pasaron.

```rust
pub fn duplicar(n: i32) -> i32 {
    n * 2
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn duplica_positivos() {
        assert_eq!(duplicar(21), 42);
    }
}
```

`#[cfg(test)]` hace que el módulo entero desaparezca en una compilación normal: los
tests no viajan al binario final.

## Las aserciones

<div class="text-sm cp-table-compact">

| Macro | Falla cuando |
| :--- | :--- |
| `assert!(cond)` | la condición es falsa |
| `assert_eq!(a, b)` | los valores difieren; imprime ambos |
| `assert_ne!(a, b)` | los valores son iguales |
| `#[should_panic]` | el test **no** entra en pánico |

</div>

Un test falla cuando entra en pánico, así que `unwrap()` sobre un `None` también
cuenta como falla. `assert_eq!` exige que el tipo implemente `PartialEq` y `Debug`
(4.1 Traits), que es lo que permite imprimir los dos valores al fallar.

## `#[should_panic]`

```rust
pub fn dividir(a: i32, b: i32) -> i32 {
    if b == 0 {
        panic!("división entre cero");
    }
    a / b
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    #[should_panic(expected = "división entre cero")]
    fn rechaza_cero() {
        dividir(1, 0);
    }
}
```

El `expected` verifica que el mensaje contenga ese texto, para no dar por bueno un
pánico distinto al esperado.

## Unitarios y de integración

<div class="text-sm cp-table-compact">

| | Unitarios | De integración |
| :--- | :--- | :--- |
| Dónde | `mod tests` en el mismo archivo | archivos sueltos en `tests/` |
| Qué ven | también lo privado | solo la API pública, vía `use mi_crate::...` |
| Para qué | una función en aislamiento | el crate como lo usaría alguien más |

</div>

Cada archivo de `tests/` se compila como un crate aparte, así que necesita importar
la librería por su nombre, igual que cualquier consumidor externo (7.2 Crates y Cargo).

## Doc-tests

````rust
/// Duplica un número.
///
/// ```
/// use katas::duplicar;
/// assert_eq!(duplicar(21), 42);
/// ```
pub fn duplicar(n: i32) -> i32 {
    n * 2
}
````

<div class="important-note">

Los ejemplos de la documentación se compilan y se ejecutan con `cargo test`. Es la
forma de que la documentación no envejezca: si el ejemplo deja de compilar, el test
falla.
