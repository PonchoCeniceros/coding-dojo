# 4.3 · Closures

---
layout: center
---

## Una función que recuerda su entorno

Un **closure** es una función anónima que puede usar las variables del lugar donde
se escribió. Los parámetros van entre barras verticales y los tipos casi siempre se
infieren.

```rust
fn main() {
    let factor = 3;
    let triple = |n: i32| n * factor;   // usa `factor` sin recibirlo

    println!("{}", triple(5));          // 15
}
```

Eso es lo que una función normal no puede hacer: `fn triple(n: i32)` no tendría forma
de ver `factor`.

## Los tres traits

Cómo usa el closure lo que capturó determina qué trait implementa. No se eligen: el
compilador asigna el más permisivo que alcance.

<div class="text-sm cp-table-compact">

| Trait | Qué hace con lo capturado | Se puede llamar |
| :--- | :--- | :--- |
| `Fn` | solo lo lee | muchas veces |
| `FnMut` | lo modifica | muchas veces, si el binding es `mut` |
| `FnOnce` | lo consume | una sola vez |

</div>

Todo `Fn` es también `FnMut` y `FnOnce`. Por eso una función que pide `FnOnce` acepta
cualquier closure, y una que pide `Fn` es la más exigente.

## `FnMut`: modificar lo capturado

```rust
fn main() {
    let mut cuenta = 0;

    let mut incrementar = || cuenta += 1;   // presta `cuenta` como &mut
    incrementar();
    incrementar();

    println!("{cuenta}"); // 2
}
```

Mientras `incrementar` viva, nadie más puede tocar `cuenta`: el closure sostiene un
préstamo exclusivo, con las mismas reglas de 3.3.

## `move`: tomar posesión

```rust
fn main() {
    let nombre = String::from("Gio");

    let saludar = move || println!("hola, {nombre}");

    saludar();
    // `nombre` ya no está disponible aquí: el closure es su dueño
}
```

<div class="important-note">

Sin `move`, el closure toma prestado y no puede sobrevivir al dato. Con `move`, se
lleva el valor consigo. Es lo que hace falta para mandar un closure a otro hilo o
devolverlo desde una función.

</div>

## Recibir un closure como parámetro

```rust
fn aplicar<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 {
    f(x)
}

fn main() {
    println!("{}", aplicar(|n| n * 2, 21));  // 42
}
```

* El parámetro es genérico con un *trait bound* (4.2 Generics): cualquier tipo que sea `Fn(i32) -> i32`.
* Cada closure tiene un tipo propio y anónimo, así que no se puede escribir `f: Fn(i32) -> i32` a secas.
* Forma equivalente y más corta: `fn aplicar(f: impl Fn(i32) -> i32, x: i32) -> i32`.
