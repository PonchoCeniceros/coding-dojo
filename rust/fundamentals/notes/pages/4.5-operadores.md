# 4.5 · Operadores y conversiones

---
layout: center
---

## Los operadores son traits

`+`, `[]`, `==` y `*` no están grabados en el lenguaje para unos tipos y prohibidos
para otros. Cada uno es un método de un trait de `std::ops`, y cualquier tipo puede
implementarlo.

```rust
use std::ops::Add;

#[derive(Debug, Clone, Copy)]
struct Punto { x: i32, y: i32 }

impl Add for Punto {
    type Output = Punto;        // el tipo asociado de 4.2
    fn add(self, otro: Punto) -> Punto {
        Punto { x: self.x + otro.x, y: self.y + otro.y }
    }
}

// Punto { x: 1, y: 2 } + Punto { x: 10, y: 20 }
// -> Punto { x: 11, y: 22 }
```

## El catálogo

<div class="text-sm cp-table-compact">

| Escrito | Trait | Método |
| :--- | :--- | :--- |
| `a + b` | `Add` | `add` |
| `a - b`, `a * b`, `a / b` | `Sub`, `Mul`, `Div` | igual |
| `-a` | `Neg` | `neg` |
| `a += b` | `AddAssign` | `add_assign` |
| `a[i]` | `Index` / `IndexMut` | `index` |
| `a == b` | `PartialEq` | `eq` |
| `a < b` | `PartialOrd` | `partial_cmp` |
| `*a` | `Deref` | `deref` |

</div>

`Index` acepta cualquier tipo de índice: una matriz puede indexarse con
`m[(fila, columna)]` implementando `Index<(usize, usize)>`.

## `Deref`: comportarse como lo que se envuelve

Explica por qué un `Box<T>` responde a los métodos de lo que guarda adentro.

```rust
use std::ops::Deref;

struct Etiqueta(String);
impl Deref for Etiqueta {
    type Target = String;
    fn deref(&self) -> &String { &self.0 }
}

// Etiqueta(String::from("hola")).len() -> 4, método de String
// fn imprimir(s: &str) acepta &etiqueta: &Etiqueta a &String a &str
```

<div class="important-note">

El compilador inserta los `*` que hagan falta hasta que los tipos cuadren: es la
*coerción de deref*. Es lo que vuelve usable el newtype de 4.4, porque el envoltorio
hereda los métodos del envuelto sin escribir ninguno.

</div>
