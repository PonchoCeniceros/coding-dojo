# 1.4 · Todo es una expresión

---
layout: center
---

## Enunciado y expresión

Un **enunciado** hace algo y no produce valor. Una **expresión** evalúa a un valor.
En Rust casi todo es lo segundo, y de ahí sale buena parte de su forma.

<div class="important-note">

El punto y coma es el que convierte una expresión en enunciado. `x + 1` vale algo;
`x + 1;` descarta ese valor y vale `()`.

</div>

---
layout: center
---

## Un bloque vale lo que su última expresión

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1        // sin `;`: este es el valor del bloque
    };

    println!("{y}"); // 4
}
```

Las llaves no son solo agrupación: `{ ... }` es una expresión con su propio valor y
su propio alcance.

## `if` devuelve valor

```rust
fn main() {
    let n = -5;
    let signo = if n < 0 { -1 } else { 1 };

    println!("{signo}"); // -1
}
```

* Por eso Rust no necesita un operador ternario.
* Las dos ramas deben dar el **mismo tipo**; si una es `i32` y la otra `&str`, no compila.
* Un `if` sin `else` vale `()`, así que no sirve para asignar.

## `match` y `loop` también

```rust
fn main() {
    let codigo = 2;
    let nombre = match codigo {
        1 => "uno",
        2 => "dos",
        _ => "otro",
    };

    let mut i = 0;
    let primero = loop {
        i += 1;
        if i * i > 50 {
            break i;      // `break` con valor: eso vale el loop
        }
    };

    println!("{nombre} {primero}"); // dos 8
}
```

## El punto y coma cambia el tipo

<div class="grid grid-cols-2 gap-x-6 mt-4 w-full text-left">
  <div>
    <span class="text-xs cp-err font-bold block mb-1">Error: el cuerpo vale `()`</span>

```rust
fn siguiente(x: i32) -> i32 {
    x + 1;
}
```

  </div>

  <div>
    <span class="text-xs cp-ok font-bold block mb-1">Válido: el cuerpo vale `i32`</span>

```rust
fn siguiente(x: i32) -> i32 {
    x + 1
}
```

  </div>
</div>

<div class="important-note">

`error[E0308]: mismatched types`. Un `;` de más al final de una función es de los
errores más frecuentes al empezar, y el mensaje suele decir *expected `i32`, found `()`*.
