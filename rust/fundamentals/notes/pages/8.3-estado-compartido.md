# 8.3 · Estado compartido

---
layout: center
---

## Dos problemas, dos tipos

Compartir un dato entre hilos exige resolver dos cosas distintas, y cada una tiene
su tipo. Confundirlas es el error más común al empezar.

<div class="text-sm cp-table-compact">

| Problema | Tipo | Equivalente mono-hilo |
| :--- | :--- | :--- |
| ¿quién es el dueño, si son varios hilos? | `Arc<T>` | `Rc<T>` (6.2 Rc, RefCell y árboles) |
| ¿cómo muto algo compartido? | `Mutex<T>` | `RefCell<T>` (6.2 Rc, RefCell y árboles) |

</div>

Por eso la forma que se ve en todos lados es `Arc<Mutex<T>>`: propiedad compartida
por fuera, mutación controlada por dentro.

layout: center
---

## `Arc<Mutex<T>>` en la práctica

```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let contador = Arc::new(Mutex::new(0));
    let mut hilos = Vec::new();

    for _ in 0..8 {
        let c = Arc::clone(&contador);
        hilos.push(thread::spawn(move || {
            let mut n = c.lock().unwrap();
            *n += 1;
        }));
    }

    for h in hilos {
        h.join().unwrap();
    }

    println!("{}", *contador.lock().unwrap()); // 8, siempre
}
```

## Qué hace `lock()`

* Devuelve un `Result` porque el mutex queda *envenenado* si un hilo entra en pánico mientras lo tiene.
* El valor que devuelve es un `MutexGuard`, que se comporta como `&mut T`.
* **El candado se suelta cuando el guard sale de alcance.** No hay `unlock()`.

<div class="important-note">

Esa última línea es la fuente de los bloqueos: si el guard se guarda en una variable
de vida larga, el candado sigue tomado. `{ *c.lock().unwrap() += 1; }` lo suelta al
cerrar la llave.

</div>

## `RwLock` cuando se lee mucho más de lo que se escribe

```rust
use std::sync::{Arc, RwLock};

fn main() {
    let config = Arc::new(RwLock::new(String::from("v1")));

    {
        let solo_lectura = config.read().unwrap();   // muchos a la vez
        println!("{solo_lectura}");
    }

    // uno solo, exclusivo
    let mut escritura = config.write().unwrap();
    *escritura = String::from("v2");
}
```

Es la regla de 3.3 —una exclusiva **o** varias compartidas— verificada en ejecución
en vez de en compilación. `Mutex` no distingue: toda toma es exclusiva.
