## Inmutable por default

En la mayoría de los lenguajes una variable es mutable salvo que se declare lo
contrario. Rust invierte el default: un binding no se puede reasignar a menos que
se marque con `mut`.

<div class="grid grid-cols-2 gap-x-6 mt-4 w-full text-left">
  <div>
    <span class="text-xs cp-err font-bold block mb-1">Error: reasignar un binding inmutable</span>

```rust
fn main() {
    let x = 5;
    x = 6;
}
```

  </div>

  <div>
    <span class="text-xs cp-ok font-bold block mb-1">Válido: binding declarado mutable</span>

```rust
fn main() {
    let mut x = 5;
    x = 6;
}
```

  </div>
</div>

<div class="important-note">

`error[E0384]: cannot assign twice to immutable variable`. La inmutabilidad por
default es el origen de buena parte de las reglas posteriores: si nada cambia,
compartir es siempre seguro.

</div>

## Shadowing

Volver a declarar un nombre con `let` no reasigna la variable: crea **una nueva**
que oculta a la anterior. El tipo puede cambiar.

```rust
fn main() {
    let entrada = "  42  ";
    let entrada = entrada.trim();                 // &str
    let entrada: i32 = entrada.parse().unwrap();  // ahora i32

    println!("{}", entrada + 1); // 43
}
```

<div class="important-note">

Es idiomático para transformar un valor por etapas sin inventar `entrada_2`,
`entrada_limpia`, `entrada_num`. Cada `let` es una variable distinta, así que el
binding puede seguir siendo inmutable.

</div>

## Shadowing frente a `mut`

<div class="text-sm cp-table-compact">

| | `mut` | shadowing |
| :--- | :--- | :--- |
| Variable | la misma | una nueva en cada `let` |
| Tipo | fijo | puede cambiar |
| Binding resultante | mutable | inmutable, salvo que se pida `mut` |
| Alcance | hasta el final del scope | hasta el final del scope, y revierte al salir del bloque |

</div>

## La sombra muere con su bloque

```rust
fn main() {
    let x = 5;
    {
        let x = x * 2;   // sombra local
        println!("{x}"); // 10
    }
    println!("{x}");     // 5: la sombra murió con el bloque
}
```

## `const` y `static`

Ninguna es una variable: exigen tipo anotado y un valor evaluable al compilar.

```rust
const MAX_INTENTOS: u32 = 3;
static SALUDO: &str = "hola";

fn main() {
    println!("{MAX_INTENTOS} {SALUDO}");
}
```

<div class="important-note">

* **`const`** se sustituye en línea en cada uso. No tiene dirección de memoria propia.
* **`static`** ocupa una sola dirección durante toda la ejecución, y su referencia vive `'static`.

</div>

Regla práctica: `const` por default; `static` solo si importa la dirección única.
