## Cómo leer este cuaderno

**El orden no es decorativo.** Las secciones están ordenadas de forma topológica:
ningún símbolo aparece antes de haberse explicado. Si lo lees de corrido, nunca vas a
tropezar con algo que no se haya presentado.

<div class="important-note">

Solo hay **dos excepciones**, y están declaradas al final de 1.2 Tipos escalares: los
literales de texto y `String`. Cualquier otra referencia hacia adelante lleva su
número de sección al lado.

</div>

**Pero también se consulta.** El Contenido es clicable, cada página cierra con un
bloque *Ver también*, y los ejercicios son un cuaderno aparte.

## Qué no es

<div class="important-note">

**No es exhaustivo, y no sustituye la documentación oficial.** Es un cuaderno de
apuntes: lo que quedó después de estudiar. Cuando no alcance, lo de abajo sí es completo.

</div>

<div class="text-sm cp-table-compact">

| Fuente | Para qué |
| :--- | :--- |
| *The Rust Programming Language* | el libro oficial, la referencia de fondo |
| *Rust by Example* | el mismo material, pero a base de ejemplos |
| `doc.rust-lang.org/std` | la biblioteca estándar, tipo por tipo |
| `rustc --explain E0382` | el manual de errores, ya instalado en tu máquina |
| `docs.rs` | la documentación de cualquier crate publicado |

</div>

Todos los bloques se compilaron con `rustc` antes de entrar. Los que fallan lo hacen
a propósito y traen su código `E0xxx` al lado.
