# 2.4 · Patrones

---
layout: center
---

## Un patrón es un constructor al revés

Se escribe **igual** que la expresión que construye el valor, pero en el lado
izquierdo. Donde al construir se ponen valores, al destructurar se ponen nombres.

<div class="text-sm cp-table-compact">

| Construir | Destructurar |
| :--- | :--- |
| `let p = (1, 2);` | `let (x, y) = p;` |
| `let p = Punto { x: 1, y: 2 };` | `let Punto { x, y } = p;` |
| `let e = Estado::Activo(3);` | `let Estado::Activo(n) = e` |
| `let a = [1, 2, 3];` | `let [primero, .., ultimo] = a;` |

</div>

Esa simetría es todo el sublenguaje: si sabes construir un valor, ya sabes escribir
el patrón que lo abre.

## Dónde aparecen

`match` es su uso más visible, pero un patrón cabe en cualquier lugar donde se liga
un nombre.

```rust
fn main() {
    let punto = (3, 7);
    let (x, y) = punto;                     // patrón en `let`

    for (i, c) in [(0, 'a'), (1, 'b')] {    // patrón en `for`
        println!("{i}{c}");
    }
    println!("{x} {y}");
}
```

<div class="important-note">

Todo `let` lleva un patrón. `let x = 5` es el caso trivial: un patrón de un solo
nombre que acepta cualquier valor. También los parámetros de una función lo son.

</div>

## Refutables e irrefutables

Un patrón es **irrefutable** si coincide siempre, y **refutable** si puede fallar.
Cada construcción admite un tipo distinto.

<div class="text-sm cp-table-compact">

| Construcción | Admite | Porque |
| :--- | :--- | :--- |
| `let`, parámetros de función, `for` | solo irrefutables | no hay rama alternativa |
| `if let`, `while let`, `match` | también refutables | existe el caso "no coincidió" |

</div>

## `let` exige un patrón que no pueda fallar

<div class="grid grid-cols-2 gap-x-6 mt-4 w-full text-left">
  <div>
    <span class="text-xs cp-err font-bold block mb-1">Error: patrón refutable en `let`</span>

```rust
enum Estado { Activo(u32), Inactivo }

fn main() {
    let e = Estado::Activo(3);
    let Estado::Activo(n) = e;
    println!("{n}");
}
```

  </div>

  <div>
    <span class="text-xs cp-ok font-bold block mb-1">Válido: `let ... else` da la salida</span>

```rust
enum Estado { Activo(u32), Inactivo }

fn main() {
    let e = Estado::Activo(3);
    let Estado::Activo(n) = e else {
        return;
    };
    println!("{n}");
}
```

  </div>
</div>

<div class="important-note">

`error[E0005]`. `let ... else` resuelve el caso de "extrae el valor o sal de aquí"
sin anidar un `if let` alrededor del resto de la función.

</div>

## Desestructurar structs y enums

El patrón replica la forma del tipo. Sirve para sacar campos por nombre y para
ramificar según los valores que contienen.

```rust
struct Punto { x: i32, y: i32 }

fn describir(p: Punto) {
    match p {
        Punto { x: 0, y: 0 } => println!("el origen"),
        Punto { x: 0, y }    => println!("sobre el eje Y, a {y}"),
        Punto { x, y: 0 }    => println!("sobre el eje X, a {x}"),
        Punto { x, y }       => println!("({x}, {y})"),
    }
}

fn main() {
    describir(Punto { x: 0, y: 7 });
}
```

* Un campo escrito como valor (`x: 0`) **filtra**; escrito como nombre (`y`) **liga**.
* Las ramas se prueban en orden y la primera que coincide gana.

## Guards, rangos, alternativas y `@`

<div class="text-sm cp-table-compact">

| Sintaxis | Qué hace |
| :--- | :--- |
| `x if cond` | *guard*: condición extra sobre lo ya ligado |
| `1..=9` | rango inclusivo |
| `10 \| 20` | alternativa: coincide con cualquiera |
| `n @ 1..=9` | liga el valor **y** comprueba el patrón |
| `_` | descarta sin ligar |
| `..` | ignora el resto de los campos o elementos |

</div>

layout: center
---

## `let else` y `matches!`

Dos atajos para los casos en que un `match` completo sobra. `let else` liga el
patrón o se sale del bloque; `matches!` responde si algo encaja, sin ligar nada.

```rust
fn largo(texto: Option<&str>) -> usize {
    let Some(t) = texto else { return 0 };  // o sale, o t existe
    t.len()                                 // t vive en toda la función
}

fn atiende(e: &Estado) -> bool {
    matches!(e, Estado::Activo | Estado::Pausado)
}
```

<div class="important-note">

El bloque del `else` no puede continuar: tiene que salir con `return`, `break`,
`continue` o un *panic*. Esa exigencia es lo que permite que `t` siga vivo después,
sin anidar el resto de la función dentro de un `if let`.

</div>

## Todo junto en un `match`

```rust
fn clasificar(n: i32) {
    match n {
        0               => println!("cero"),
        x if x < 0      => println!("negativo"),
        d @ 1..=9       => println!("un dígito: {d}"),
        10 | 100 | 1000 => println!("potencia de diez"),
        _               => println!("otro"),
    }
}

fn main() {
    clasificar(7);
}
```
