# 7.5 · Entrada y salida

---
layout: center

## Leer y escribir un archivo

```rust
use std::fs;

fn main() -> Result<(), std::io::Error> {
    fs::write("saludo.txt", "hola")?;

    let contenido = fs::read_to_string("saludo.txt")?;
    println!("{contenido}");

    Ok(())
}
```

<div class="important-note">

`main` puede devolver `Result`, y por eso el `?` (5.2 Result) funciona aquí. Si devuelve
`Err`, el proceso termina con código distinto de cero y el error se imprime con
`Debug`.

</div>

## Archivos grandes: línea por línea

```rust
use std::fs::File;
use std::io::{BufRead, BufReader};

fn main() -> Result<(), std::io::Error> {
    let archivo = File::open("datos.txt")?;

    for linea in BufReader::new(archivo).lines() {
        println!("{}", linea?);
    }

    Ok(())
}
```

`read_to_string` carga todo en memoria. `BufReader` lee por bloques y entrega un
iterador (5.6 Iteradores) de líneas, cada una como un `Result`.

## Leer de la entrada estándar

```rust
use std::io::{self, BufRead};

fn main() {
    let entrada = io::stdin();

    for linea in entrada.lock().lines() {
        let linea = linea.unwrap();
        println!("leí: {linea}");
    }
}
```

Es la forma habitual en jueces en línea y en filtros de línea de comandos. El `lock()`
evita bloquear y desbloquear la entrada en cada línea.

## Argumentos de la línea de comandos

```rust
use std::env;

fn main() {
    let args: Vec<String> = env::args().collect();

    match args.get(1) {
        Some(nombre) => println!("hola, {nombre}"),
        None => println!("uso: programa <nombre>"),
    }
}
```

<div class="important-note">

`args[0]` es la ruta del ejecutable, así que los argumentos reales empiezan en 1.
Usar `.get(1)` en vez de `args[1]` evita el *panic* cuando no se pasó nada: devuelve
`Option` (5.1 Option).

</div>
