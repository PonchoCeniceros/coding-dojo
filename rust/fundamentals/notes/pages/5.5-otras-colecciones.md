# 5.5 · Otras colecciones

---
layout: center
---

## Cuál usar

<div class="text-sm cp-table-compact">

| Colección | Para qué | Costo típico |
| :--- | :--- | :--- |
| `Vec<T>` | secuencia, acceso por índice | índice O(1), push al final O(1) |
| `VecDeque<T>` | cola: se mete y se saca por los dos extremos | O(1) en ambos extremos |
| `HashMap<K, V>` | clave → valor, sin orden | O(1) promedio |
| `BTreeMap<K, V>` | clave → valor, **ordenado** por clave | O(log n) |
| `BinaryHeap<T>` | siempre sacar el mayor | insertar O(log n), ver el máximo O(1) |

</div>

`HashSet` y `BTreeSet` son las versiones sin valor de sus mapas.

## `VecDeque`: cola por los dos extremos

```rust
use std::collections::VecDeque;

fn main() {
    let mut cola = VecDeque::new();

    cola.push_back(1);
    cola.push_back(2);
    cola.push_front(0);

    println!("{:?}", cola.pop_front());   // Some(0)
    println!("{:?}", cola);               // [1, 2]
}
```

Un `Vec` puede quitar del frente con `remove(0)`, pero eso mueve todos los elementos:
O(n) cada vez. `VecDeque` es lo correcto para un BFS o un buffer.

## `BinaryHeap`: el máximo, siempre a la mano

```rust
use std::collections::BinaryHeap;
use std::cmp::Reverse;

fn main() {
    let mut mayores = BinaryHeap::from([3, 1, 4, 1, 5]);
    println!("{:?}", mayores.pop());        // Some(5)

    let mut menores = BinaryHeap::new();    // min-heap
    for n in [3, 1, 4] {
        menores.push(Reverse(n));
    }
    let Reverse(minimo) = menores.pop().unwrap();
    println!("{minimo}");                   // 1
}
```

<div class="important-note">

Es **max-heap**. Para el mínimo se envuelve en `std::cmp::Reverse`, que invierte el
`Ord` (4.4 Traits de la stdlib). Es el descuido más común al usarlo.

</div>

## `BTreeMap`: recorrido en orden

```rust
use std::collections::BTreeMap;

fn main() {
    let mut ventas = BTreeMap::new();
    ventas.insert("marzo", 30);
    ventas.insert("enero", 10);
    ventas.insert("febrero", 20);

    for (mes, monto) in &ventas {
        println!("{mes}: {monto}");   // enero, febrero, marzo
    }

    println!("{:?}", ventas.first_key_value());   // Some(("enero", 10))
}
```

La llave necesita `Ord` en vez de `Hash + Eq`. Es más lento que `HashMap`, y a cambio
permite recorrer en orden y pedir rangos.
