# 7.6 · Macros y atributos

---
layout: center
---

## Por qué importan aunque no las escribas

En cuanto entres a librerías reales vas a ver `#[derive(Serialize)]`,
`#[tokio::main]` y `#[sqlx::query]`. No hace falta saber escribirlas, pero sí saber
**qué hacen con tu código**, porque los errores que producen apuntan a código que
nunca escribiste.

<div class="text-sm cp-table-compact">

| Forma | Qué es | Ejemplo |
| :--- | :--- | :--- |
| `nombre!(...)` | macro invocada | `println!`, `vec!`, `format!` |
| `#[derive(X)]` | macro de derivación: **agrega** un `impl` | `#[derive(Debug, Clone)]` |
| `#[algo]` | macro de atributo: **reescribe** lo que decora | `#[tokio::main]`, `#[test]` |

</div>

## Una macro no es una función

```rust
fn main() {
    let v = vec![1, 2, 3];
    println!("{} elementos", v.len());
}
```

* Se expanden **antes** de compilar: generan código fuente, no se llaman en ejecución.
* Por eso aceptan un número variable de argumentos, y `println!` puede verificar el formato en compilación.
* El `!` está para que se note: lo que sigue no obedece las reglas de una llamada normal.

## `derive` agrega implementaciones

```rust
#[derive(Debug, Clone, PartialEq)]
struct Punto { x: i32, y: i32 }
```

Eso equivale a escribir a mano tres bloques `impl` (4.4 Traits de la stdlib). El derive los genera a
partir de los campos.

<div class="important-note">

Un derive de un crate externo funciona igual: `#[derive(Serialize)]` genera el `impl
Serialize for T` que la librería necesita. Por eso hay que importar el trait, y por
eso el error dice que *falta un `impl`* cuando se olvida el derive.

</div>

## Los atributos reescriben

```rust
#[cfg(test)]
mod tests {
    #[test]
    fn funciona() {
        assert!(true);
    }
}
```

<div class="text-sm cp-table-compact">

| Atributo | Efecto |
| :--- | :--- |
| `#[cfg(test)]` | el elemento solo existe al compilar los tests |
| `#[allow(...)]` / `#[deny(...)]` | activa o apaga una advertencia |
| `#[derive(...)]` | agrega implementaciones |
| `#[tokio::main]` | envuelve la función en un runtime (9.3 El runtime) |

</div>

## Cómo ver lo que generan

```bash
cargo install cargo-expand
cargo expand
```

<div class="important-note">

`cargo expand` imprime el código después de expandir todas las macros. Es la
herramienta para entender un error que apunta a una línea que no escribiste, y la
forma más rápida de ver qué hace realmente `#[tokio::main]`.

</div>
