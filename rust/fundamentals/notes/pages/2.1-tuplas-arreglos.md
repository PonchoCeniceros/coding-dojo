## Dos colecciones de tamaño fijo

Ambas conocen su longitud en tiempo de compilación, así que caben en el stack.
Un arreglo es homogéneo; una tupla no.

## Acceso y desestructuración

```rust
fn main() {
    let arr: [i32; 3] = [1, 2, 3];
    let t: (i32, char, bool) = (42, 'z', true);

    let primero = arr[0];        // por índice
    let (n, c, activo) = t;      // por desestructuración

    println!("{primero} {n} {c} {activo}");
}
```

* Un arreglo se indexa; el índice fuera de rango provoca *panic*.
* Una tupla se desestructura o se accede por posición (`t.0`, `t.1`).
* La desestructuración ya es un patrón; los patrones a fondo están en 2.4.
