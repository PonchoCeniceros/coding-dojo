# Paralelismo de datos

---
layout: center

## Concurrencia no es paralelismo

<div class="text-sm cp-table-compact">

| | Concurrencia | Paralelismo |
| :--- | :--- | :--- |
| Qué es | varias tareas **en progreso** a la vez | varias tareas **ejecutándose** a la vez |
| Necesita | una forma de intercalar | varios núcleos |
| Herramienta | hilos, canales, async (9) | hilos sobre datos divisibles |

</div>

Todo lo anterior de esta sección sirve para las dos. Lo que sigue es el caso
particular en el que la misma operación se aplica a muchos datos independientes.

---
layout: center
---

## El caso: la misma operación sobre muchos datos

```rust
fn main() {
    let datos: Vec<u64> = (1..=1_000_000).collect();

    let suma: u64 = datos.iter()
        .map(|n| n * n)
        .sum();

    println!("{suma}");
}
```

Cada elemento se procesa sin depender de los demás. Repartirlo entre núcleos es
mecánico, pero hacerlo a mano con `thread::spawn` significa dividir el vector,
lanzar hilos, recolectar y sumar parciales.

## `rayon`: el mismo código, en paralelo

```rust
use rayon::prelude::*;

fn main() {
    let datos: Vec<u64> = (1..=1_000_000).collect();

    let suma: u64 = datos.par_iter()
        .map(|n| n * n)
        .sum();

    println!("{suma}");
}
```

<div class="important-note">

`iter()` pasa a `par_iter()` y ya. `rayon` es un crate externo, no parte del
lenguaje, pero se apoya por completo en `Send` y `Sync`: si el closure captura algo
que no los cumple, no compila. Es la garantía de 8.2 dando resultado.

</div>

---
layout: center
---

## Cuándo vale la pena

* El trabajo por elemento debe ser real: para sumar un millón de enteros, coordinar hilos cuesta más que la suma.
* Los elementos deben ser independientes. Si el resultado de uno alimenta al siguiente, no es paralelizable así.
* Todo lo capturado por el closure tiene que ser `Send` y `Sync`.

<div class="important-note">

Es la base del cómputo paralelo en Rust y de librerías como **Polars**, que ejecutan
operaciones sobre columnas repartidas entre núcleos con este mismo modelo.

</div>
